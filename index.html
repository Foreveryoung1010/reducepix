Image compression FAQ

Are my images uploaded?

No. PixelCrate processes images inside your browser with the Canvas API. Image content is not sent to, stored on, or processed by a PixelCrate server.

Can I compress several images at once?

Yes. Add multiple JPG, PNG or WebP files and PixelCrate applies the same settings to each file. Download results one by one or together.

Can I compress an image to 100KB?

You can set a target size in kilobytes. PixelCrate searches for the highest quality that meets the target when the selected format supports quality-based compression. Results depend on image content and browser capabilities.

What is the maximum file size?

There is no fixed server upload limit because files stay on your device. Large images use more browser memory, so practical limits depend on your device and available RAM.
